# Security Policy

## Reporting a Vulnerability

脆弱性を発見した場合は、公開 Issue ではなく GitHub の [Private Vulnerability Reporting](https://github.com/Takenori-Kusaka/AIWebUITester/security/advisories/new) から報告してください。

Please report vulnerabilities via GitHub's [Private Vulnerability Reporting](https://github.com/Takenori-Kusaka/AIWebUITester/security/advisories/new), not public issues.

- 初回応答の目安 / Initial response: 7 days
- 修正はリリースノートで告知します / Fixes are announced in release notes

## Supported Versions

プレリリース段階のため、常に最新リリースのみをサポート対象とします。
Only the latest release is supported during the pre-1.0 phase.
